# Evaluation contract

Construction source only: neither scorer nor generator has run. Proposed size400 and bootstrap2000 are settings, not measured counts. Run only after Dirty Mode closes and dependency/provider validation is authorized.

## Data and freezing
`npm run eval -- --freeze` generates the synthetic set in memory, validates duplicate-value grouping, and freezes `fixtures/synthetic-manifest.json` before live dev tuning. The canonical study identity/hash pins generator/seed/requested size/variant, all group-to-split assignments and group metadata, counts, sample population keys/groups/splits/labels, run-2 identities, preregistered target0.98/disabled equivalence, and policy/prefix/prompt/schema configuration. Both top-level frozen assignments and the stored identity/hash must match regeneration; lifecycle markers alone may change. A mismatch is rejected, never overwritten under the old freeze date. Prior files are preserved as .bak-N. No raw generator output is written. A private identity salt lives only in gitignored `.eval-local/identity-salt.bin`; guard salt/index is fresh and memory-only. All outputs name author-written synthetic data and its chosen trap prevalence; no natural-population generalisation.

The Node loader parses original candidates to join labels using original scanner/path/line/rule, then uses numeric `sourceRecordIndices` from the shared pipeline. Sanitized paths and random HMAC IDs never control labels, sample identity or metric denominators. A separate no-folder pipeline pass supplies the paired match-line ablation. Independent allowlist facts use raw-time stopword/path/entropy arithmetic, never application signal labels.

## Rows and operating points
(a) scanner (all surfaced); (b) **gitleaks-style allowlist emulation (unwrapped)** uses independent booleans, not a scanner rerun; (c) deterministic-only; (d) **LLM-only (masked-view guard)** uses masked ±1 context without signals/deterministic stage; (e) deterministic+generative; (f) deterministic+Jev, experimental unless it earns inclusion. Pure in-process methods classify without serialising the whole Finding; unrelated metadata/digest collisions cannot silently wrap emulation or suppress a call whose actual view is safe. Every actual model view still passes the mandatory privacy guard. View-blocked candidates stay in denominators/review; readable reports show guard-blocked coverage. Report keys/scalars and complete artifacts are guarded before writing. Unsafe path-dismiss is eval-only, and match-line uses a separate no-folder pipeline pass.

`npm run eval` is keyless scripted interface replay. Live rows without factories say not run and certify no tuning. M5 supplies budgeted factories. Before any configured live held-out call (including exploratory repeats), thresholds must be `dev-tuned` with validated live lineage binding the frozen study hash, exact dev population/count/real count, threshold hash, and operating hash of provider/model/adapter descriptors plus policy/prompt/schema config. Untuned, edited or unrelated artifacts fail closed. `--live --tune` runs DEV first; tuneDev rejects mock/held-out inputs and its artifact is written before any held-out marker/call. A genuine infeasible conservative no-dismiss dev result is valid lineage. No factory means no dispatch/held-out marker and no pretend certification. The first live attempt is marked before dispatch; repeat requires `--exploratory`, is labelled descriptive, cannot produce a primary headline or earn preregistered promotion. Held-out curves remain descriptive.

## Statistics
Automated bands only, before audit or human decisions. Surface=keep or review. Candidate recall=surfaced real/all real; FP reduction=1-surfaced negatives/all negatives. Also review rate, keep precision, calls/tokens/USD per1000, fresh and cached latency separately. Any zero denominator is N/A. Guard-blocked candidates remain in denominators and conservatively review; unsafe input is never exported merely to score it.

Recall interval is Wilson95%. FP reduction and paired differences use fixed-seed group cluster bootstrap; all compared methods share identical resampled groups. Undefined replicates are counted/excluded. Scoreless methods contribute one curve point, and unattainable matched recall is explicit, never interpolated into a fictitious comparison. Primary R=.98; .95/.99 descriptive. Jev promotion requires attainable matched recall and superiority intervals strictly above zero against BOTH deterministic-only and generative; no equivalence/cost-only branch. Native probabilities alone establish no calibration.

## Artifact lineage and cost
One EvaluationResult plus dataset metadata writes results/results.md, results/results.jsonl, docs/LIMITATIONS.md and README CLAIM block. Limitations lists every suppressed real candidate by evaluator key/trap/signals, surviving false positives and LLM-only wins. No raw values, source paths/context or identity salts enter reports/cache/ledger. All artifact text passes the combined known-value guard before writes.

Each method carries its configured judge descriptor and operating configuration even when no call is needed or a paired row is not run. Readable results render provider/model/adapter/kind, threshold values/source/hash, study/config identity and dev lineage from the same object as JSONL. Mock identity is explicit. Cache identity includes those versions and the masked request hash. Fresh numeric usage is copied/validated independently before optional result text or cache insertion can fail; such failures conservatively review while retaining live origin and measured latency. Adapter failure receipts preserve known numeric spend; a dispatched attempt with no valid receipt makes aggregate usage N/A, never zero. Replay spend is excluded and cached latency remains separate. The cache is empty in construction. `JUDGE_EVAL_USD` overrides the eval cap; live attempts/retries still require M5 reservations.
